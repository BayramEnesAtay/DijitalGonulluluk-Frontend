## 🎯 About the Project

Finding reliable volunteering opportunities and managing volunteer teams is often a disconnected process. **Volunion** solves this by providing a centralized ecosystem where:
* **Volunteers** can discover projects that match their skills and interests.
* **Organizations** can post events, track participation, and manage their workforce efficiently.
* **Impact** is measured through digital tracking and feedback loops.

---

## 🏆 Hackathon Context

This project was conceived, designed, and developed during a **Hackathon**. 
* **Timeframe:** Built under strict time constraints (e.g., 48 hours).
* **Team:** Developed by a dedicated team of 3 developers.
* **Focus:** Rapid prototyping, functional MVP (Minimum Viable Product), and social impact.

---

## 🚀 Key Features

* **Smart Matching:** Filters volunteering opportunities based on location, interests, and availability.
* **Organization Dashboard:** Tools for NGOs to create events and view applicant profiles.
* **Volunteer Profiles:** A digital portfolio showcasing a user's past volunteering history and skills.
* **Real-time Interaction:** Integration for instant updates on application status (Accepted/Pending).
* **Secure Authentication:** User verification and login systems.

## 💻 Installation

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/BayramEnesAtay/DijitalGonulluluk-VOLUNION.git](https://github.com/BayramEnesAtay/DijitalGonulluluk-VOLUNION.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd DijitalGonulluluk-VOLUNION
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Configure Environment:**
    * Create a `.env` file in the root directory.
    * Add your Firebase API keys and configuration details.

5.  **Run the application:**
    ```bash
    npm start
    ```
    *The app will launch in your browser at `http://localhost:3000`.*
